# LENDVESTRA website prototype

## Pages
- `index.html` — public homepage
- `signin.html` — separate demo sign-in page
- `signup.html` — separate demo sign-up page
- `loan-application.html` — separate loan application preview
- `investment-enquiry.html` — separate investment enquiry preview
- `portal.html` — combined customer portal demo
- `admin.html` — fictional admin dashboard preview

The uploaded LENDVESTRA logo is used in the header across pages. The navigation links are visible on desktop and available from the menu button on smaller screens.

## Important
This is a front-end prototype only. Sign-in is simulated; requests are not sent or persisted. Admin statistics are fictional. Do not use it to collect real customer information or accept money. Production requires secure backend authentication, database access controls/RLS, server-side validation, audit logs, payment reconciliation, and legal/compliance/security review. Never expose privileged keys in frontend files.

## Publish
For a GitHub Pages preview, upload all files and the `assets` folder to the repository root, then enable Settings → Pages → Deploy from a branch → `main` → `/(root)`.
